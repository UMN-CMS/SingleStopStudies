\section{Introduction}
\label{sec:introduction}

\begin{frame}{Analysis Target}
  \begin{itemize}
  \item Searching for the production and decay of a single \stop{} to 4 standard model quarks through an RPV coupling. 
  \item Targeting both $\lambda_{312}'',\lambda_{313}'' \in [0.1,0.4]$.
    \begin{itemize}
    \item Intermediate values between long lived ($\lambda < 0.1$) and direct dijet decays ($\lambda > 0.4$)
    \end{itemize}
  \item Well motivated channel to look for SUSY \cite{evans_lhc_2013}:
    \begin{itemize}
    \item Unexplored region of RPV parameter space
    \item Large cross section allows us to probe higher masses
    \end{itemize}
  \item For more information see the talks shown on Slide~\ref{frame:past-presentations}.
  \end{itemize}

\section{Trigger Efficiencies}
\label{sec:trigger-efficiencies}

\begin{frame}{Description}
  \begin{itemize}
    
  \item The triggers used in our analysis are \trig{PFHT*} and \trig{AK8PFJet*}
  \item Trigger efficiencies are computed relative \trig{IsoMu*}.
  \end{itemize}
\end{frame}

\begin{frame}{Trigger Object Definition}
  \begin{description}
  \item[Good Muon] $p_{T} > 30 $ and $|\eta| < 2.4$ and Medium Cut Id and $\text{miniRelIso}<0.1$
  \item[Good Electron] $p_{T} > 10 $ and $|\eta| < 2.4$ and Tight Cut Id and $\text{miniRelIso}<0.1$
  \item[Good Jet] $p_{T} > 30 $ and $|\eta| < 2.4$ and no good muon within $\Delta R < 0.4$
  \item[Good Fat Jet] $p_{T} > 175 $ and $|\eta| < 2.4$ and no good muon within $\Delta R < 0.4$
  \item[HT] Sum of good jet $p_{T}$
  \end{description}
\end{frame}

\begin{frame}{Key Points}
  
  \begin{itemize}
  \item Run2 looks very good, we do not see any issues with using MC for studies.
  \item Run3 shows greater discrepancies between QCD MC and Data. Separate data/data comparisons have shown that the data is not the issue.
  \item In the reconstruction plots, the effect that causes this discrepancy seems to be reduced.
  \item We are not sure what exactly is causing this discrempancy, and we would ask for your expert input.
  \end{itemize}
\end{frame}

\section[Significance]{Preliminary Significance Studies}
\label{sec:prel-sign-stud}


\begin{frame}{Description}
  \begin{itemize}
  \item We perform expected significance studies using QCD Simulation
  \item We have also performed studies using control region data. The method works identically, but the background has a slightly different shape. 
  \item Signifcances are computed using the complete background estimation procedure described in previous talks.
  \item Most important systematic -- the Gaussian Process Regression uncertainty -- is included in combine card. 
  \item Smaller MC systematics that affect the exact signal shape are not included yet. 
  \end{itemize}
\end{frame}
